# Customer-feedback-encapsulation-workflow-system

## Frontend — Start

Prerequisites: Node.js (v16+ recommended) and npm installed.

1. Install dependencies

```bash
cd frontend
npm install
cd ../backend
npm install
```

2. Start development server
in powershell
```bash
Start-Process cmd -ArgumentList '/k','cd /d backend && npm run dev' ; Start-Process cmd -ArgumentList '/k','cd /d frontend && npm run dev'
```bash

The app will be available at http://localhost:5173 by default.
